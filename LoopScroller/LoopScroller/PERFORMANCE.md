# 1.1.0 性能验证

验证日期：2026-09-23。构建目标：.NET 8 x64 自包含。

## 可重复基准

`LoopScroller.Tests --benchmark` 在同一进程中比较原版画刷平铺与新版图片片段平移，输入为 2000 个中英文段落，输出尺寸 1920×1080；预热后各采集 360 帧。

| CPU 离屏绘制耗时 | 原版 | 新版 |
| --- | ---: | ---: |
| 中位数 | 136.78 ms | 85.46 ms |
| P95 | 147.50 ms | 92.00 ms |
| P99 | 153.61 ms | 95.78 ms |

此样本的中位耗时下降约 37.5%。离屏绘制使用 `RenderTargetBitmap`，包含截图生成成本，不是屏幕呈现 FPS；不能据此推断目标电脑达到 60 FPS。

十分钟逻辑播放模拟以 60 次/秒、150 DIP/秒共推进 36000 次，按加速方式运行约 24.3 秒。片段缓存结束时为 94.48 MiB，过程中未超出 96 MiB 预算。该测试验证位置推进及缓存周转，并非十分钟真实屏幕播放。

另验证 120 次连续小幅推进时只更新平移变换，不生成新图片、不重建显示片段。

## 验收边界

- 回归覆盖图片、TXT、DOCX、循环分割线、高 DPI 接缝、滚轮、300% 缩放及 150 速度上限。
- 大跨度跳到冷缓存位置仍可能等待首次生成；首次文档排版仍与文档长度有关。
- 原图、完整排版对象和图形系统副本不计入 96 MiB 片段缓存预算；重排切换时新旧文档会短暂共存。
- 未在用户的 Windows 10 教育版电脑上实测刷新率，也没有干净虚拟机可验证。已有 .NET 8 版曾由用户确认可运行，新版仍沿用相同发布方式。
